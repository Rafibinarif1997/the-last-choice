# THE LAST CHOICE — Prototype

A zero-cost, no-npm prototype for the interactive NFT concept.

## Run
Just open `index.html` in a browser.

## Deploy
Upload these 3 files to a GitHub repository and enable GitHub Pages:
- index.html
- style.css
- app.js

## Current prototype
- 3 sample artifacts (#017, #023, #041)
- 5 permanent decisions per artifact
- evolving generated artwork
- story history
- path rarity
- final form reveal
- localStorage progress
- responsive mobile/desktop UI

This is NOT a real blockchain NFT yet. It is the product/mechanic prototype.
